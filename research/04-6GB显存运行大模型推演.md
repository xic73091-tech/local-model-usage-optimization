# 6GB显存运行大模型深度推演

## 一、显存占用分析基础

### 1.1 显存组成

```
总显存占用 = 模型权重 + KV Cache + 运行时开销 + 激活值
```

**详细分解：**

| 组件 | 说明 | 典型占比 |
|------|------|----------|
| 模型权重 | Transformer层的参数 | 60-80% |
| KV Cache | 注意力机制的Key/Value缓存 | 10-25% |
| 运行时开销 | CUDA context、cuBLAS工作区 | 300-500MB固定 |
| 激活值 | 前向传播的中间结果 | 5-15% |

### 1.2 模型参数量与显存关系

**FP16基准：**
```
显存(GB) = 参数量(B) × 2字节
```

| 模型 | 参数量 | FP16显存 | INT8显存 | INT4显存 |
|------|--------|----------|----------|----------|
| 7B | 70亿 | 14 GB | 7 GB | 3.5 GB |
| 13B | 130亿 | 26 GB | 13 GB | 6.5 GB |
| 30B | 300亿 | 60 GB | 30 GB | 15 GB |
| 70B | 700亿 | 140 GB | 70 GB | 35 GB |

## 三、6GB显存运行推演

### 3.1 基础计算模型

```python
def calculate_vram_requirement(
    model_size_b: float,      # 模型参数量(B)
    quantization_bits: float,  # 量化位数
    context_length: int,       # 上下文长度
    num_layers: int,           # 模型层数
    num_heads: int,            # 注意力头数
    head_dim: int,             # 每头维度
    batch_size: int = 1,       # 批大小
) -> dict:
    """计算显存需求"""

    # 1. 模型权重
    bytes_per_param = quantization_bits / 8
    model_weight_gb = model_size_b * bytes_per_param

    # 2. KV Cache (FP16基准)
    # KV Cache = 2(K+V) × 层数 × 头数 × 头维度 × 序列长度 × 批大小
    kv_cache_bytes = 2 * num_layers * num_heads * head_dim * context_length * batch_size
    kv_cache_gb = kv_cache_bytes / (1024**3)

    # 3. 运行时开销
    overhead_gb = 0.4  # CUDA context + cuBLAS

    # 4. 激活值 (估算)
    activation_gb = model_size_b * 0.01  # 约1%的模型大小

    total_gb = model_weight_gb + kv_cache_gb + overhead_gb + activation_gb

    return {
        "model_weight_gb": round(model_weight_gb, 2),
        "kv_cache_gb": round(kv_cache_gb, 2),
        "overhead_gb": round(overhead_gb, 2),
        "activation_gb": round(activation_gb, 2),
        "total_gb": round(total_gb, 2),
    }
```

## 四、突破6GB限制的优化策略

### 4.1 策略一：GPU-CPU混合卸载

**核心思想：将部分层卸载到CPU**

```python
def calculate_gpu_cpu_split(
    model_size_gb: float,
    num_layers: int,
    available_vram_gb: float,
    overhead_gb: float = 0.4,
) -> dict:
    """计算GPU/CPU层分配"""

    # 预留显存给开销和部分KV Cache
    usable_vram = available_vram_gb - overhead_gb - 0.2  # 0.2GB给KV Cache

    # 计算每层大小
    per_layer_gb = model_size_gb / num_layers

    # 计算GPU能放多少层
    gpu_layers = int(usable_vram / per_layer_gb)
    gpu_layers = max(0, min(gpu_layers, num_layers))

    cpu_layers = num_layers - gpu_layers

    return {
        "gpu_layers": gpu_layers,
        "cpu_layers": cpu_layers,
        "gpu_usage_gb": round(gpu_layers * per_layer_gb, 2),
        "cpu_usage_gb": round(cpu_layers * per_layer_gb, 2),
    }
```

**13B Q3_K_M + GPU-CPU混合：**

```
模型大小: 13B × 0.44 = 5.72 GB
层数: 40层
每层大小: 5.72 / 40 = 0.143 GB

可用显存: 5.5 - 0.4(开销) - 0.2(KV) = 4.9 GB
GPU层数: 4.9 / 0.143 = 34层
CPU层数: 40 - 34 = 6层

GPU显存: 34 × 0.143 = 4.86 GB ✅
CPU内存: 6 × 0.143 = 0.86 GB

预估速度: ~20-25 tokens/s（受CPU层影响）
```

**✅ 13B模型可在6GB显存运行！**

### 4.2 策略二：KV Cache量化

**将KV Cache从FP16量化到INT8/INT4**

```python
def kv_cache_quantization_savings(
    num_layers: int,
    num_heads: int,
    head_dim: int,
    context_length: int,
    original_bits: int = 16,
    target_bits: int = 8,
) -> dict:
    """计算KV Cache量化节省"""

    # 原始大小
    original_bytes = 2 * num_layers * num_heads * head_dim * context_length * (original_bits / 8)
    original_gb = original_bytes / (1024**3)

    # 量化后大小
    quantized_bytes = 2 * num_layers * num_heads * head_dim * context_length * (target_bits / 8)
    quantized_gb = quantized_bytes / (1024**3)

    savings_gb = original_gb - quantized_gb
    savings_percent = (savings_gb / original_gb) * 100

    return {
        "original_gb": round(original_gb, 3),
        "quantized_gb": round(quantized_gb, 3),
        "savings_gb": round(savings_gb, 3),
        "savings_percent": round(savings_percent, 1),
    }
```

### 4.5 策略五：动态层加载 + 预取

**按需加载层，减少同时驻留显存的层数**

```python
class DynamicLayerLoader:
    """动态层加载器"""

    def __init__(self, max_gpu_layers: int = 20):
        self.max_gpu_layers = max_gpu_layers
        self.layer_cache = {}  # GPU层缓存
        self.access_order = []  # LRU顺序

    async def get_layer(self, layer_idx: int):
        """获取层，必要时从CPU加载"""
        if layer_idx in self.layer_cache:
            # 命中GPU缓存
            self._update_access(layer_idx)
            return self.layer_cache[layer_idx]

        # 未命中，需要加载
        if len(self.layer_cache) >= self.max_gpu_layers:
            # 淘汰最久未使用的层
            evict_idx = self.access_order.pop(0)
            await self._unload_to_cpu(evict_idx)

        # 从CPU加载到GPU
        layer = await self._load_from_cpu(layer_idx)
        self.layer_cache[layer_idx] = layer
        self.access_order.append(layer_idx)

        return layer
```

**动态加载效果：**

```
原始方案：40层全部在GPU = 5.72 GB
动态加载：20层在GPU + 20层按需加载

显存占用: 20 × 0.143 = 2.86 GB
加上其他: 2.86 + 0.35 + 0.40 + 0.13 = 3.74 GB

✅ 大幅降低显存占用！
```

### 4.6 策略六：激活值检查点 (Activation Checkpointing)

**不保存所有激活值，需要时重新计算**

```python
def activation_checkpointing_savings(
    num_layers: int,
    activation_per_layer_gb: float,
    checkpoint_interval: int = 4,
) -> dict:
    """计算激活值检查点节省"""

    # 原始：保存所有层的激活值
    original_gb = num_layers * activation_per_layer_gb

    # 检查点：只保存每N层的激活值
    checkpoint_layers = num_layers // checkpoint_interval
    checkpointed_gb = checkpoint_layers * activation_per_layer_gb

    savings_gb = original_gb - checkpointed_gb
    savings_percent = (savings_gb / original_gb) * 100

    return {
        "original_gb": round(original_gb, 2),
        "checkpointed_gb": round(checkpointed_gb, 2),
        "savings_gb": round(savings_gb, 2),
        "savings_percent": round(savings_percent, 1),
    }
```

**激活值检查点效果：**

```
原始激活值: 40层 × 0.02 GB = 0.80 GB
检查点后: 10层 × 0.02 GB = 0.20 GB
节省: 0.60 GB (75%)
```

```python
def estimate_performance(
    gpu_layers: int,
    total_layers: int,
    quantization: str,
    dynamic_loading: bool,
) -> dict:
    """预估性能"""

    # 基准速度 (7B Q4_K_M, 全GPU, 中端GPU)
    base_tps = 40.0

    # 参数量惩罚 (13B比7B慢)
    size_penalty = 7.0 / 13.0  # 0.54

    # 量化速度因子
    quant_factor = {
        "Q4_K_M": 1.3,
        "Q3_K_M": 1.2,
        "Q2_K": 1.5,
    }.get(quantization, 1.0)

    # GPU层比例
    gpu_ratio = gpu_layers / total_layers

    # 动态加载惩罚
    dynamic_penalty = 0.85 if dynamic_loading else 1.0

    # 计算最终速度
    tps = base_tps * size_penalty * quant_factor * gpu_ratio * dynamic_penalty

    return {
        "estimated_tps": round(tps, 1),
        "tokens_per_minute": round(tps * 60, 0),
        "suitable_for_chat": tps >= 10,
        "suitable_for_streaming": tps >= 5,
    }
```

## 七、优化技术实现

### 7.1 极低精度量化支持

```python
# src/optimization/ultra_quantizer.py

"""极低精度量化模块
支持 Q2_K, IQ2_XXS, IQ3_XXS 等极低精度量化格式。
"""

from dataclasses import dataclass
from enum import Enum
from typing import Dict, Optional

class UltraQuantLevel(Enum):
    """极低精度量化级别"""
    Q2_K = "Q2_K"           # 2.9 bits
    IQ2_XXS = "IQ2_XXS"     # 2.1 bits
    IQ2_XS = "IQ2_XS"       # 2.3 bits
    IQ2_S = "IQ2_S"         # 2.5 bits
    IQ3_XXS = "IQ3_XXS"     # 3.1 bits
    IQ3_S = "IQ3_S"         # 3.4 bits
    IQ4_XS = "IQ4_XS"       # 4.3 bits

@dataclass
class UltraQuantProfile:
    """极低精度量化画像"""
    level: UltraQuantLevel
    bits_per_param: float
    vram_per_billion_gb: float
    quality_score: float       # 0-1
    speed_factor: float        # 相对于Q4_K_M的速度
    description: str

# 量化级别注册表
ULTRA_QUANT_PROFILES: Dict[UltraQuantLevel, UltraQuantProfile] = {
    UltraQuantLevel.Q2_K: UltraQuantProfile(
        level=UltraQuantLevel.Q2_K,
        bits_per_param=2.9,
        vram_per_billion_gb=0.31,
        quality_score=0.55,
        speed_factor=1.2,
        description="2-bit量化，显存最小，质量损失较大",
    ),
    UltraQuantLevel.IQ2_XXS: UltraQuantProfile(
        level=UltraQuantLevel.IQ2_XXS,
        bits_per_param=2.1,
        vram_per_billion_gb=0.26,
        quality_score=0.45,
        speed_factor=1.1,
        description="极限2-bit量化，需要特殊支持",
    ),
    UltraQuantLevel.IQ3_XXS: UltraQuantProfile(
        level=UltraQuantLevel.IQ3_XXS,
        bits_per_param=3.1,
        vram_per_billion_gb=0.37,
        quality_score=0.60,
        speed_factor=1.15,
        description="3-bit极限量化，质量略好于Q2",
    ),
}

class UltraQuantizer:
    """极低精度量化管理器"""

    def recommend_for_vram(
        self,
        model_size_b: float,
        available_vram_gb: float,
        min_quality: float = 0.5,
    ) -> Optional[UltraQuantLevel]:
        """根据显存推荐极低精度量化级别"""

        for level in [UltraQuantLevel.IQ3_XXS, UltraQuantLevel.Q2_K, UltraQuantLevel.IQ2_XXS]:
            profile = ULTRA_QUANT_PROFILES[level]
            vram_needed = model_size_b * profile.vram_per_billion_gb

            if vram_needed <= available_vram_gb and profile.quality_score >= min_quality:
                return level

        return None

    def estimate_vram(
        self,
        model_size_b: float,
        level: UltraQuantLevel,
    ) -> float:
        """估算显存需求"""
        profile = ULTRA_QUANT_PROFILES[level]
        return model_size_b * profile.vram_per_billion_gb
```

### 7.2 高级卸载策略

```python
# src/optimization/advanced_offloader.py

"""高级模型卸载模块
支持更精细的层分配策略，包括：
- 基于层重要性的智能分配
- 注意力层优先GPU
- 预测性预取
"""

import math
from dataclasses import dataclass
from typing import List, Tuple

@dataclass
class LayerImportance:
    """层重要性评估"""
    layer_idx: int
    importance_score: float    # 0-1
    is_attention_layer: bool
    estimated_compute_time_ms: float

class AdvancedOffloader:
    """高级卸载器"""

    def calculate_importance_based_allocation(
        self,
        num_layers: int,
        model_size_gb: float,
        available_vram_gb: float,
        overhead_gb: float = 0.4,
    ) -> Tuple[List[int], List[int]]:
        """基于重要性的层分配"""

        # 评估每层的重要性
        layers = self._estimate_layer_importance(num_layers)

        # 按重要性排序
        sorted_layers = sorted(layers, key=lambda x: x.importance_score, reverse=True)

        # 贪心分配：优先把重要层放GPU
        gpu_layers = []
        cpu_layers = []
        remaining_vram = available_vram_gb - overhead_gb

        per_layer_gb = model_size_gb / num_layers

        for layer in sorted_layers:
            if remaining_vram >= per_layer_gb:
                gpu_layers.append(layer.layer_idx)
                remaining_vram -= per_layer_gb
            else:
                cpu_layers.append(layer.layer_idx)

        return sorted(gpu_layers), sorted(cpu_layers)

    def _estimate_layer_importance(self, num_layers: int) -> List[LayerImportance]:
        """估算每层的重要性

        基于研究发现：
        - 早期层（特征提取）更重要
        - 注意力层比FFN层更重要
        - 中间层相对不那么重要
        """
        layers = []

        for i in range(num_layers):
            # 位置权重：早期和晚期层更重要
            position_weight = 1.0 - 0.3 * math.sin(math.pi * i / num_layers)

            # 注意力层权重（假设奇数层是注意力）
            is_attention = (i % 2 == 0)
            attention_weight = 1.2 if is_attention else 0.8

            # 综合重要性
            importance = position_weight * attention_weight
            importance = min(max(importance, 0.0), 1.0)

            layers.append(LayerImportance(
                layer_idx=i,
                importance_score=importance,
                is_attention_layer=is_attention,
                estimated_compute_time_ms=10.0,  # 估算值
            ))

        return layers
```

### 7.3 智能KV Cache管理

```python
# src/optimization/smart_kv_cache.py

"""智能KV Cache管理
实现更激进的KV Cache优化策略：
- 基于注意力分数的稀疏化
- 动态精度调整
- 前缀树共享
"""

import math
from dataclasses import dataclass
from typing import Dict, List, Optional
from collections import OrderedDict

@dataclass
class KVCacheBudget:
    """KV Cache显存预算"""
    max_size_gb: float
    current_size_gb: float
    utilization_percent: float

class SmartKVCacheManager:
    """智能KV Cache管理器"""

    def __init__(self, max_size_gb: float = 1.0):
        self.max_size_gb = max_size_gb
        self.cache = OrderedDict()  # seq_id -> cache_data
        self.attention_scores = {}  # seq_id -> attention_scores

    def estimate_optimal_context(
        self,
        model_size_b: float,
        num_layers: int,
        available_vram_gb: float,
        quant_bits: int = 8,
    ) -> int:
        """估算最优上下文长度"""

        # KV Cache公式：2 × 层数 × 头维度 × 序列长度 × 精度
        # 简化：每层每1K上下文约0.5MB (FP16)
        base_per_layer_per_1k = 0.5  # MB

        # 量化调整
        quant_factor = quant_bits / 16.0

        # 可用于KV Cache的显存
        kv_budget_mb = available_vram_gb * 1024 * 0.3  # 30%给KV Cache

        # 计算最大上下文
        max_context_1k = kv_budget_mb / (num_layers * base_per_layer_per_1k * quant_factor)

        # 向下取整到最近的1024
        max_context = int(max_context_1k) * 1024

        # 限制范围
        max_context = max(512, min(max_context, 32768))

        return max_context

    def compress_by_attention_score(
        self,
        cache_data: List,
        attention_scores: List[float],
        target_size: int,
    ) -> List:
        """基于注意力分数压缩KV Cache"""

        if len(cache_data) <= target_size:
            return cache_data

        # 计算每个位置的重要性
        importance = [(i, score) for i, score in enumerate(attention_scores)]

        # 按重要性排序
        importance.sort(key=lambda x: x[1], reverse=True)

        # 保留最重要的位置
        keep_indices = sorted([idx for idx, _ in importance[:target_size]])

        return [cache_data[i] for i in keep_indices]
```
